# CS-320 Services Application Testing Reflection

# How can I ensure that my code, program, or software is functional and secure?
I can ensure that my code is functional and secure by following software requirements carefully and validating all user input. Throughout this project, I used JUnit tests to verify that each class and service behaved as expected under both valid and invalid conditions. Testing helped confirm that data validation rules were enforced correctly and prevented invalid information from entering the system. Security and reliability both improve when software handles unexpected input appropriately and consistently.

# How do I interpret user needs and incorporate them into a program?
I interpret user needs by analyzing the project requirements and translating them into specific program features and validation rules. For this project, the customer requirements defined restrictions such as maximum field lengths, required values, and appointment date limitations. I incorporated these needs by implementing validation logic within each class and then creating tests to verify that the requirements were met. This process helped ensure that the final product aligned with the customer's expectations and business rules.

# How do I approach designing software?
I approach software design by first reviewing the requirements and identifying the classes, data, and functionality needed to solve the problem. I then break the project into smaller, manageable components that each have a specific responsibility. For this project, I designed separate Contact, Task, and Appointment classes along with service classes responsible for managing those objects. Once the structure was established, I implemented validation rules and developed unit tests to verify functionality. This approach helped create software that was organized, maintainable, and easier to test and debug.
